Chain Query `too many values`. Description

When querying via API or Strawberry, the generated query returns an error:

```gql
query MyQuery {
  chain(chainName: "Another Chain") {
    steps {
      prompt {
        chainName
        promptCategory
        commandName
        promptName
      }
      agentName
      promptType
      step
    }
    chainName
    id
  }
}
```

```
{
  "data": null,
  "errors": [
    {
      "message": "too many values to unpack (expected 2)",
      "locations": [
        {
          "line": 2,
          "column": 3
        }
      ],
      "path": [
        "chain"
      ]
    }
  ]
}
```
